# Margin Kit — seller spreadsheet demo

A public, free Excel demo that estimates per-unit profit, margin, break-even price and target-price scenarios for one product at a time.

- [Open the demo page](https://dark12ggdg4.github.io/margin-calculator-pilot/)
- [Download the sample workbook](seller_margin_calculator_demo.xlsx)
- [View the service/demo PDF](seller_margin_service_demo.pdf)

The workbook keeps fee rates editable; it does not claim current marketplace tariffs. The built-in candle example is illustrative: at a $32 sale price, the supplied assumptions produce $11.95 estimated profit and a $17.70 break-even price.

A one-product custom setup is shown as a proposed US$10 pilot price only. It is not a validated market rate or a guarantee of a sale. The page does not process payments: scope and a compliant commercial payment method must be confirmed before any order or work. Do not send money through an unverified link.

For general questions, use a GitHub issue without posting confidential cost, customer or account details. This repository and issues are public.
